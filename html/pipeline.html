국가망 보안체계(N2SF) 패러다임 전환 및 합성데이터 활용 구조

기존 경계 기반의 물리적 망분리(AS-IS)에서 데이터 중심의 다층보안체계(TO-BE)로의 변화와
S구역(민감) 데이터의 합성데이터(SDV) 변환을 통한 O구역(공개) 안전 개방 시나리오

AS-IS

과거 물리적 망분리 (경계 중심 보안 모델)

(외부) 인터넷망
공공 Cloud / 생성형 AI
국방 데이터 활용 불가
물리적 망 단절 (Wall)
데이터 쇄국 (Data Silo 심화)
(내부) 국방·공공 업무망
내부 폐쇄망 정보자산
외부 접속 전면 차단
데이터 중심 보안(Data-Centric Security)으로 패러다임 전환
TO-BE

N2SF 다층보안체계 (Multi-Level Security, MLS)

데이터 민감도 평가 기반 차등 공유
High Level

C 구역 (Classified / 기밀)

국가안보 직결 핵심 기밀 및 무기체계 제원

  • 인터넷 연결 전면 차단 (물리적 단절 유지)
  • 최고 수준의 물리·논리적 접근 통제
  • 원본 데이터 외부 반출 절대 불가
기존 물리적 망분리 수준 유지
Mid Level (핵심 연구 대상)

S 구역 (Sensitive / 민감)

통제 미분류 정보(CUI), 사이버 로그, 운용 데이터

  • 제한적 외부 연결 허용 (조건부 통제)
  • SDV(CTGAN) 기반 합성데이터 변환 적용
  • 재식별 위험 제거 후 O구역으로 안전 반출
합성 데이터 변환 O구역 반출 허용
Low Level

O 구역 (Open / 공개)

일반 공공 데이터 및 검증된 합성데이터

  • 공공 클라우드 & 생성형 AI 전면 활용
  • 산·학·연 외부 공동 연구 및 데이터 개방
  • 방산 인재 양성 및 교육용 데이터셋 배포
외부 연구 및 산학연 협력 활성화

본 논문 핵심 매커니즘: S구역 ➔ O구역 합성데이터 반출 프로세스

SDV(Synthetic Data Vault) 및 CTGAN 알고리즘을 통한 기밀 유출 차단 및 유용성 보존 단계

1
원본 수집 (S구역)
LANL 인증로그 / 방산 프록시 정형 데이터
2
SDV 모델 학습
CTGAN 확률분포 및 상관구조 학습
3
가상 데이터 생성
원본 1:1 매칭 무실재 인공 데이터 생성
4
유용성·보안 검증
SDV Evaluate (유사도 88%+ 확보)
5
O구역 안전 반출
산학연 교육/연구망 안전 개방
준비 완료: 버튼을 누르면 S구역 데이터의 O구역 변환 과정을 확인할 수 있습니다. Status: IDLE
